# iOSショートカット セットアップ手順

## 全体の流れ

```
iPhone で写真を複数選択（またはカメラ撮影）
  → 保存先フォルダを選ぶ（既存から選択 or 新規作成）
  → 選んだ写真を1枚ずつ処理：
       Live Text OCR で日付・時刻を読み取る
       → "20250607_1430_receipt.jpg" 形式でファイル名を生成
       → Google Apps Script に画像を送信
  → Google Drive の選択フォルダに全枚数を保存完了
```

---

## ステップ1：Google Apps Script のデプロイ

1. [script.google.com](https://script.google.com) を開き、新規プロジェクトを作成
2. `Code.gs` の内容を貼り付ける
3. **2箇所を書き換える：**
   - `FOLDER_ID` → Google DriveフォルダURLの末尾のID  
     例: `https://drive.google.com/drive/folders/` **`1ABCxxxxxx`** ← これ
   - `SECRET_TOKEN` → 任意のランダム文字列（例: `myReceipt2024abc`）
4. 「デプロイ」→「新しいデプロイ」→ 種類: **ウェブアプリ**
   - 実行ユーザー: **自分**
   - アクセスできるユーザー: **全員**（匿名を許可）
5. 「デプロイ」ボタン → **ウェブアプリのURL** をコピーして保存

---

## ステップ2：iOSショートカットの作成

「ショートカット」アプリを開き、「+」で新規作成。
以下の順にアクションを追加する。構成は **A. 写真を選ぶ → B. 保存先フォルダを決める → C. 1枚ずつ送信（繰り返し）** の3ブロック。

> 💡 URL・トークンは何度も使うので、先頭に **テキスト** アクションを2つ置いて
> 変数 `WebアプリURL`（ステップ1のURL）と `トークン`（`SECRET_TOKEN` の値）に保存しておくと便利。

### A. 写真を選ぶ

**① 写真を選択**
- アクション名: `写真を選択`
- 設定: **「複数を選択」をオン** ← これで複数枚まとめて選べる
- 結果を変数 `写真リスト` に保存

> カメラで撮ってから送りたい場合は代わりに `写真を撮る` を使い、
> 複数枚撮るなら `写真を撮る` を「繰り返す」で囲む。基本は `写真を選択` が手軽。

### B. 保存先フォルダを決める

**② フォルダ一覧を取得**
- アクション名: `URLの内容を取得`
- URL: `WebアプリURL`
- メソッド: `POST`、ヘッダー: `Content-Type: application/json`
- リクエスト本文（JSON）: `{ "action": "getFolders", "token": トークン }`
- 結果を変数 `フォルダ応答` に保存

**③ フォルダ名のリストを作る**
- `フォルダ応答` から各項目の `name` を取り出す（`辞書の値を取得` → キー `name`、すべての値）
- 末尾に固定項目 `＋ 新規フォルダを作成` を追加
- 結果を変数 `メニュー項目` に保存

**④ メニューから選ぶ**
- アクション名: `メニューから選択` … 入力を `メニュー項目` にする
- **「＋ 新規フォルダを作成」が選ばれた場合：**
  - `入力を要求`（テキスト）で新フォルダ名を尋ねる → 変数 `新フォルダ名`
  - `URLの内容を取得` で POST：
    `{ "action": "createFolder", "name": 新フォルダ名, "token": トークン }`
  - 応答の `id` を変数 `保存先フォルダID` に保存
- **既存フォルダ名が選ばれた場合：**
  - `フォルダ応答` の中から名前が一致する項目の `id` を取り出し、変数 `保存先フォルダID` に保存

### C. 1枚ずつ送信（繰り返し）

**⑤ 各写真について繰り返す**
- アクション名: `繰り返す（それぞれ）` … 入力を `写真リスト` にする
- 以下 ⑥〜⑬ を**この繰り返しの中**に入れる（`繰り返し項目` = その回の写真）

**⑥ OCR（テキストを認識）**
- 入力: `繰り返し項目` → 結果を変数 `OCRテキスト` に保存

**⑦ 日付パターンを取得**
- `テキストを照合`（正規表現）… 入力 `OCRテキスト`
- 正規表現: `(\d{4})[年/\-\.](\d{1,2})[月/\-\.](\d{1,2})`
- 結果を変数 `日付マッチ` に保存

**⑧ 時刻パターンを取得**
- `テキストを照合` … 入力 `OCRテキスト`
- 正規表現: `(\d{1,2}):(\d{2})`
- 結果を変数 `時刻マッチ` に保存

**⑨ 日付を整形**
- `テキストを置き換える`… 入力 `日付マッチ`（最初のマッチ）
- `年`/`/`/`-`/`.` を空白に置換 → 変数 `日付`（例: `20250607`）

> **フォールバック：** `if 日付 が空` → `今日の日付` を `yyyyMMdd` で取得 → `日付`

**⑩ 時刻を整形**
- `テキストを置き換える`… 入力 `時刻マッチ`（最初のマッチ）
- `:` → 空白 → 変数 `時刻`（例: `1430`）

> **フォールバック：** `if 時刻 が空` → `今すぐ` を `HHmm` で取得 → `時刻`

**⑪ ファイル名を組み立てる**
- `テキスト`: `[日付]_[時刻]_receipt.jpg` → 変数 `ファイル名`

> 同じ日付・時刻の写真が複数あると同名になり得る。心配なら末尾に
> `繰り返しインデックス`（例: `..._receipt_1.jpg`）を足すと衝突を防げる。

**⑫ Base64エンコード**
- `Base64でエンコード`… 入力 `繰り返し項目` → 変数 `画像Base64`

**⑬ Google Apps Script に送信**
- `URLの内容を取得`… URL `WebアプリURL`、メソッド `POST`
- ヘッダー: `Content-Type: application/json`
- リクエスト本文（JSON）:
  ```json
  {
    "image": 画像Base64,
    "filename": ファイル名,
    "folderId": 保存先フォルダID,
    "token": トークン,
    "mimeType": "image/jpeg"
  }
  ```

（ここで繰り返し終わり）

**⑭ 結果を表示**
- 繰り返しの**後ろ**に `通知を表示`
- 内容: `[写真リストの数] 枚を保存しました`

---

## ショートカットの使い方

1. ホーム画面にショートカットを追加（ウィジェット or アイコン）
2. タップ → 写真を複数選択
3. 保存先フォルダを選ぶ（または「＋ 新規フォルダを作成」で作る）
4. 各写真の日付・時刻を自動読み取り → 選んだフォルダに順次保存
5. 「3 枚を保存しました」と通知

## トラブルシューティング

| 症状 | 対処 |
|------|------|
| 日付が読み取れない | 撮影し直す（明るい場所で水平に）/ フォールバックで今日の日付が使われる |
| "Unauthorized" エラー | ショートカットの `token` が `Code.gs` の `SECRET_TOKEN` と一致しているか確認 |
| ファイルが保存されない | `FOLDER_ID` が正しいか確認。フォルダIDはURLの末尾 |
| フォルダ一覧が空 | `FOLDER_ID` のフォルダに親があるか確認。新規作成した親直下に兄弟フォルダとして並ぶ |
| 新規フォルダが作られない | `createFolder` を追加後に **再デプロイ**したか確認（旧デプロイは古いコードのまま） |
| 一部の写真だけ保存される | 繰り返しの中でエラー時に止まらないよう、⑬の後に成功可否のログ表示を入れて確認 |
| OCRが動かない | 設定 → 一般 → 言語と地域 → Live Text がオンになっているか確認 |
