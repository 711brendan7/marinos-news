# ガチャ・トレカ転売リサーチ

ガチャガチャ景品・レゴ・トレカ等の「仕入れ値 vs 実売相場」を自動リサーチして
黒字化しうる候補を洗い出すスクリプト群。物販（[[project_busshin]]）とは別系統で、
こちらは商品単位のスクリーニングに特化。

## 主なスクリプト

- `products.py` — スキャン対象の商品リスト（中央区の実店舗巡回で仕入れた品目）
- `scan_all.py` — 全店スキャン。`products.py` の各商品についてメルカリ「コンプ」実売中央値を取得
- `mercari_price.py` / `mercari_sold.py` — メルカリ実売相場（売り切れ）の取得
- `ebay_sold.py` — eBay Sold/Completed 価格のUSD中央値取得
- `suruga.py` — 駿河屋（中古卸）の在庫価格取得
- `rank.py` — 問屋カートン仕入れモデルで全品の利益を試算しランキング化
  （利益/コンプ = median - median\*0.10 - 送料 - 定価コンプ\*掛け率）
- `q1_singles.py` / `q2_haiban.py` / `q4_jp.py` / `q_lego.py` / `q_saturn.py` —
  個別ジャンル（シングルカード・廃盤品・国内限定・レゴ・その他IP）ごとの検証スクリプト

## 運用メモ

- 結果は `*.json` / `*.log` として都度出力される使い捨てファイル（gitignore対象）
- 実行するだけで発注は行わない（読み取り専用のリサーチツール）
